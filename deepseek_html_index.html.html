Comment utiliser Koola ?

Bienvenue ! Ce guide vous explique pas à pas comment gérer votre poulailler : ajouter des dépenses, enregistrer des ventes, suivre vos lots et synchroniser en temps réel entre appareils.

① Démarrage② Dépenses③ Revenus ④ Lots⑤ Tableau de bord⑥ Modifier ⑦ Sauvegarde⑧ Sync⑨ FAQ
1

🚀 Démarrage en 3 étapes

  • Choisissez votre devise dans le menu ☰ en haut à gauche.
  • Ajoutez votre premier lot dans l'onglet 🐣 Lots.
  • Puis enregistrez vos dépenses et revenus au fur et à mesure.
Les données sont sauvegardées automatiquement dans votre navigateur. Activez la sync Firebase pour les partager entre appareils.
2

💸 Ajouter une dépense

Onglet 💸 Dépenses : remplissez date, catégorie, montant et cliquez Ajouter.

3

💰 Ajouter un revenu

Onglet 💰 Revenus : choisissez le type (œufs, poulets, cailles, escargot…), la quantité et le montant.

4

🐣 Gérer les lots

Chaque lot = une bande de poulets avec sa date d'arrivée, son nombre de sujets et sa mortalité.

Taux de mortalité en rouge au-delà de 10 %, en vert en dessous de 5 %.
5

📊 Lire le tableau de bord

4 indicateurs clés + 3 graphiques. Filtrez par période en haut à droite.

6

✏️ Modifier ou supprimer

Dans chaque tableau : ✏️ pour modifier, 🗑 pour supprimer.

La suppression est irréversible.
7

💾 Sauvegarde locale

Depuis le menu ☰ (en haut à gauche) :

  • ⬇ Exporter : télécharge un fichier .json avec toutes vos données.
  • ⬆ Importer : recharge un fichier précédemment exporté.
  • 🗑 Réinitialiser : efface tout.
Exportez au moins une fois par semaine pour ne rien perdre.
8

🔥 Synchronisation Firebase

Partagez vos données entre appareils instantanément.

Étape préalable obligatoire : Activez d'abord Realtime Database dans votre console Firebase (voir étape A.5 ci-dessous). Sinon, la synchronisation ne fonctionnera pas.

Où trouver le panneau ?

👉 Ouvrez le menu ☰, puis cliquez sur 🔥 Sync Firebase.

A. Créer votre projet Firebase

  1. Allez sur console.firebase.google.com (compte Google).
  2. Ajouter un projet → nommez → Créer.
  3. Cliquez sur l'icône Web </> → surnom → Enregistrer.
  4. Copiez le bloc firebaseConfig.
  5. ⚠️ IMPORTANT : menu Compilation → Realtime Database → Créer une base de données → choisir un emplacement → démarrer en mode test.
  6. Menu Compilation → Authentication → Sign-in method → Anonyme → Activer.

B. 1ᵉʳ appareil

  1. Menu ☰ → 🔥 Sync Firebase.
  2. Collez le firebaseConfig (le databaseURL est détecté automatiquement).
  3. Cliquez sur ✨ Créer une chambre.
  4. Copiez le code obtenu.

C. Autres appareils

  1. Menu ☰ → 🔥 Sync Firebase.
  2. Collez le même firebaseConfig.
  3. Collez le même code.
  4. Cliquez sur 🔗 Rejoindre.
🔥 Temps réel : modifiez sur un appareil, l'autre se met à jour en moins d'1 seconde.
Le code de chambre est secret.

D. Règles de sécurité

{
  "rules": {
    "rooms": {
      "$room": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}
